# Сайт кинолога: услуги, курсы, блог, партнёрская программа

Шаблон сайта специалиста по услугам (кинолог, тренер, мастер). Без внешних библиотек, нужен только Node.js 20 или новее.

## Запуск

Windows: дважды щёлкнуть start.bat. Любая система: `npm start`. Сайт откроется на http://localhost:3000, админка на /admin. Пароль админки создаётся при первом запуске и лежит в config.json (на хостинге задаётся переменной ADMIN_PASSWORD).

## Что можно менять в админке без правки файлов

- Сайт и SEO: имя, контакты, фото и рассказ о кинологе, галерея, город для заголовков, номер Яндекс Метрики, коды Яндекс Вебмастера и Google, картинка для соцсетей.
- Услуги и тарифы: название, цена, единица цены, что входит, фото. У каждой своя страница.
- Курсы: цена (в том числе за сутки проживания), программа, фото.
- Блог: статьи с текстом, фото и видео (YouTube, RuTube, VK Видео, mp4), черновики, дата, свои заголовок и описание для поиска.
- Истории питомцев: фото до и после, видео, показ только с согласия владельца.
- Фото: загрузка файлов до 6 МБ, библиотека.
- Оплата: ЮKassa, Робокасса, Т-Банк и CloudPayments (бета), тестовый режим.
- Партнёрка: ставки по трём линиям отдельно для курсов и услуг, сроки удержания, минимальная выплата.

## SEO

Заголовок и описание на каждой странице, адрес canonical, Open Graph, микроразметка schema.org (LocalBusiness, Service, Article, BreadcrumbList, FAQPage), sitemap.xml с датами, robots.txt, человекопонятные адреса. Пока в админке не указан домен, сайт закрыт от индексации.

## Ниша

Тексты, цены и статьи стартового наполнения лежат в content/*.json и попадают в базу при первом запуске. Для другой ниши замените эти файлы и удалите data/db.json.

## Публикация

Демо: Render (файл render.yaml). Боевой сайт: сервер в РФ (папка deploy/). Загруженные фото и база хранятся рядом с db.json (папка uploads); на бесплатном тарифе Render они стираются при перезапуске.
